# Caça Quarks

Joc educatiu de l'activitat *La Força que ens uneix* (Facultat de Física, Universitat de Barcelona).

Apareix un barió amb els seus nombres quàntics (càrrega elèctrica, isospí I₃, estranyesa, encant, bellesa).
Recorre el laberint i captura els 3 quarks que el formen. Forma'n 3 i entra al Saló de la Fama.

**Juga-hi:** obre `index.html` al navegador, o la versió en línia a GitHub Pages.

Controls: `W A S D` / fletxes per moure's, ratolí per girar, `ESPAI` per capturar, `⌫` per alliberar un quark.
